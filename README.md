# 喵键盘 (Miao Keyboard)

> 一只会「喵化」的 Android 文本增强小工具 —— 基于无障碍服务（AccessibilityService）的输入辅助与文本处理助手。

## 简介

喵键盘（Miao Keyboard）通过无障碍服务读取 / 替换输入框文本，按可配置规则为文字加上猫猫语气（句末加喵、颜文字、语气调整等），并提供基于 WebView 的设置中心与本地 / 在线模型引擎。

## 功能特性

- **喵化规则引擎**：句末加喵 / 颜文字 / 语气微调，支持概率与场景开关
- **设置中心（WebView）**：功能 / 自动化 / 调校 / 对话 / 我的 五个视图
- **模型引擎**：内置本地模型（Qwen2.5）+「模型引擎 · API」独立窗口（OpenAI 兼容接口，支持测试连接）
- **自动化**：悬浮窗猫爪按钮、手动触发、无障碍事件监听

## 安装

1. 从 Releases 下载对应 APK；
2. 允许「安装未知来源应用」；
3. 安装后按引导开启无障碍服务与悬浮窗权限。

## 签名

本仓库发布的 APK 均使用同一调试签名（`CN=Android Debug`，SHA-256 `8a35ac81...`），可直接覆盖升级。
